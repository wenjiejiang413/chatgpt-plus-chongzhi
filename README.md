## 30 秒结论

- 有能境外支付的外币卡 → 官网直接订阅，最省钱
- 常用 iPhone，有外区 Apple ID → App 内订阅
- 都没有，想保留自己的账号 → 选「原账号充值」类代充，不交密码
- 只是偶尔用用 → 先用免费版，碰到使用上限再说

## 各方式要点

**官网信用卡**
- 登录 chatgpt.com → 账号菜单 → 升级套餐 → Plus
- 国内双币卡先确认已开通境外线上支付

**苹果 App Store**
- ChatGPT App 未在国区 App Store 上架，需要外区 Apple ID
- 取消订阅：设置 → Apple ID → 订阅
- 退款由 Apple 处理

**Google Play**
- 需要支持地区的 Google 账号和可用付款方式，国内门槛较高

**虚拟信用卡**
- 实际成本 = 官方价 + 开卡费 + 充值手续费 + 汇率差
- 部分卡段已被风控，开卡前先查清楚

## 原账号充值 vs 成品号

| | 原账号充值 | 成品号 |
|:--|:--|:--|
| 账号归属 | 你自己的 | 卖家提供 |
| 聊天记录和 GPTs | 保留 | 无法迁移 |
| 需要提供 | Session（登录凭证） | 无 |
| 风险点 | Session 交给了谁 | 账号可能被收回 |

Session 可以在 `chatgpt.com/api/auth/session` 页面看到，在有效期内可访问账号，只提交给可信的平台。

## 代充平台检查清单

- [ ] 不要账号密码，不要短信或邮箱验证码
- [ ] 页面写明总价和档位，付款后不加价
- [ ] 写明 Session 无效、充值失败、缺货时如何处理
- [ ] 付款后有可联系的售后渠道
- [ ] 说明是原账号充值还是成品号

示例：[MixLivo](https://mixlivo.com/guides/chatgpt-plus-recharge) 为原账号充值模式，Plus 分 ¥148 / ¥168 两档，付款后在订单页提交 Session 自动开通，不需要密码，不发卡密；少数账号只能走 ¥168 档。Pro 与 Claude Pro 为人工办理。

## 常见问题

**充值后在哪里确认生效？**
刷新 chatgpt.com，在账号设置里查看当前套餐是否为 Plus。

**会不会封号？**
没有渠道能保证绝对不出问题，风控由 OpenAI 决定。降低风险：用原账号方式、不交密码、不与他人共用账号。

**Plus 和免费版差多少？**
主要差在使用上限、可用模型和文件分析等能力。免费版经常不够用时，再考虑升级。
