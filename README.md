## 各方式要点

**官网信用卡**

- 登录 chatgpt.com → 账号菜单 → 升级套餐 → Plus
- 国内双币卡先确认已开通境外线上支付

**苹果 App Store**

- ChatGPT App 未在国区 App Store 上架，需要外区 Apple ID
- 取消订阅：设置 → Apple ID → 订阅
- 退款由 Apple 处理
- 详见：[苹果手机怎么开通 ChatGPT Plus](https://mixlivo.com/guides/chatgpt-plus-iphone)

**Google Play**

- 需要支持地区的 Google 账号和可用付款方式，国内门槛较高

**虚拟信用卡**

- 实际成本 = 官方价 + 开卡费 + 充值手续费 + 汇率差
- 部分卡段已被风控，开卡前先查清楚

**原账号代充**

- 用支付宝付款，付款后提交 Session，由平台给你自己的账号开通，不需要账号密码
- 完整步骤和到账验收：[ChatGPT Plus 充值：国内怎么买、怎么开通](https://mixlivo.com/guides/chatgpt-plus-recharge)

**成品号**

- 账号是卖家注册的，会员也开在卖家的账号上
