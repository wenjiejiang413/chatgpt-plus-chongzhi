## 各方式要点

**官网信用卡**

- 登录 chatgpt.com → 账号菜单 → 升级套餐 → Plus
- 国内双币卡先确认已开通境外线上支付

**苹果 App Store**

- ChatGPT App 未在国区 App Store 上架，需要外区 Apple ID
- 取消订阅：设置 → Apple ID → 订阅
- 退款由 Apple 处理
- 详见：[苹果手机怎么开通 ChatGPT Plus](https://mixlivo.com/guides/chatgpt-plus-iphone)

**Google Play**

- 需要支持地区的 Google 账号和可用付款方式，国内门槛较高

**虚拟信用卡**

- 实际成本 = 官方价 + 开卡费 + 充值手续费 + 汇率差
- 部分卡段已被风控，开卡前先查清楚

**原账号代充**

- 付款后提交 Session，由平台给你自己的账号开通
- 完整步骤：[ChatGPT Plus 充值教程](https://mixlivo.com/guides/chatgpt-plus-recharge-tutorial)

## 原账号充值 vs 成品号

|            | 原账号充值         | 成品号     |
| :--------- | :------------ | :------ |
| 账号归属       | 你自己的          | 卖家提供    |
| 聊天记录和 GPTs | 保留            | 无法迁移    |
| 需要提供       | Session（登录凭证） | 无       |
| 风险点        | Session 交给了谁  | 账号可能被收回 |

Session 可以在 `chatgpt.com/api/auth/session` 页面看到，在有效期内可访问账号，只提交给可信的平台。

## Session 常见问题

| 现象         | 原因            | 处理                    |
| :--------- | :------------ | :-------------------- |
| 页面只有 `{}`  | 浏览器没登录或登录过期   | 先在同一浏览器登录 chatgpt.com |
| 邮箱不是要开通的账号 | 浏览器登录了别的账号    | 退出后换账号登录              |
| 一直转圈或人机验证  | 网站在做安全检查      | 完成验证后刷新               |
| 提示格式不对     | 没复制完整或被翻译插件改动 | 关闭自动翻译，从 `{` 复制到 `}`  |
| App 里打不开   | 这个地址只能在浏览器打开  | 换用浏览器                 |

- &#x20;不要账号密码，不要短信或邮箱验证码
